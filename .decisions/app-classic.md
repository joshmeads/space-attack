- All themes share one bare black 4:3 playfield, centered at the largest shared whole-number multiple of 320 by 240 that fits the available viewport. Tiny viewports below 320 by 240 use a fractional fit. Modern retains full-resolution drawing and device-pixel ratio within that identical stage size. Header, cabinet, status chrome, footer, slogans and controls outside the game have been removed. Touch controls remain below the playfield when touch input is available.
- Title, pause and game-over menus retain only game actions, required controls, theme selection, audio preferences and local scores. Their layout is identical across Classic, Retro and Modern; theme colors can change.
- Classic is the default for fresh validated preferences. T cycles Classic, Retro and Modern; menus also offer the three explicit choices. Query theme overrides accept all three. Cached renderer selection preserves the exact core object and RNG.
- The app uses the shared HUD layout contract for the prior-best score. Classic omits its text label while keeping the value at the same logical anchor as the other themes.
- Pause uses original generated pixel glyphs for its heading and arcade text actions. R starts a fresh game only while paused; Enter continues. Music and sound rows share fixed label, state and hotkey columns so M and N align.
